## 3. `_trend_strength` 机制

### 3.1 计算公式（`supertrend_tema_strategy_v2.py:332`）

```python
def _trend_strength(self, df, idx, lookback=20):
    prices = df["close"].iloc[idx - lookback + 1: idx + 1].values
    up = down = 0.0
    for j in range(1, len(prices)):
        if prices[j] > prices[j - 1]:
            up += prices[j] - prices[j - 1]
        else:
            down += prices[j - 1] - prices[j]
    total = up + down
    return abs(up - down) / total if total > 0 else 0
```

**物理含义**：近 20 根 K 线内，上涨幅度总和 vs 下跌幅度总和的偏向程度。

| trend_str | 含义 |
|-----------|------|
| 0.0 | 涨跌幅度完全相等（横盘） |
| 0.3 | 约 65% vs 35% 偏向 |
| 0.5 | 约 75% vs 25% 偏向 |
| 1.0 | 纯单边（0 回撤） |

### 3.2 当前实测值

以 2026-06-27 19:15 时刻为例（ETH 已从 1579 涨至 1606，明显上升趋势）：

| 指标 | 值 |
|------|-----|
| `trend_str` | **0.419** |
| `is_strong` | **False**（需 >0.6） |
| `price` | 1606.97 |
| ST | 1（多头） |

### 3.3 趋势强度偏低的原因

ETH 从 ~1570 涨到 ~1606 的过程中存在多次 3~5 美元的微小回撤，在 20 根 K 线（100 分钟）的窗口内，这些回撤幅度被累加进 `down`，稀释了 `up - down` 的净差值。

大盘需要持续单边上涨相当长时间，`trend_str` 才能突破 0.6。在反弹初期（如前 2~4 小时），`trend_str` 通常在 0.2~0.5 之间。

## 5. L7 `_three_line_upward` 的额外门槛

L7 是唯一不依赖 `is_strong` 的多头条件（`supertrend_tema_strategy_v2.py:758`）：


`_three_line_upward` 内部三道关（`supertrend_tema_strategy_v2.py:395`）：

```python
def _three_line_upward(self, df, ind, idx, tema72_slope):
    # 关卡1：6 根 K 线涨幅 ≥ 0.8%
    price_chg = (close[idx] - close[idx-6]) / close[idx-6]
    if price_chg < 0.008 or abs(tema72_slope) < 0.0003:
        return False

    # 关卡2~4：连续 3 次回看检查（p=0,1,2）
    for p in range(3):
        ci = idx - p       # 当前/1根前/2根前
        tp = 6 + p         # 回看 6/7/8 根
        # price、tema48、tema72、tema288 全部要求当前 > 回看
        if not (close[ci] > close[ci-tp] and
                tema48[ci] > tema48[ci-tp] and
                tema72[ci] > tema72[ci-tp] and
                tema288[ci] > tema288[ci-tp]):
            return False
    return True
```

| 关卡 | 条件 | 19:15 实测 |
|------|------|-----------|
| 关卡1 | 6 根涨幅 ≥ 0.8% | 估算约 0.6~0.7%（未达） |
| 关卡1 | tema72 斜率 ≥ 0.0003 | 0.777 ✅ |
| 关卡2(p=0) | 6 根前：close/t48/t72/t288 全 ↑ | 不确定 |
| 关卡3(p=1) | 7 根前：close/t48/t72/t288 全 ↑ | 不确定 |
| 关卡4(p=2) | 8 根前：close/t48/t72/t288 全 ↑ | 大概率失败 |

关卡 2~4 要求 3 个连续 check point（相隔 1 根 K 线）的 4 维度（价格+3 条 TEMA）全部方向向上。涨势初期，回看窗口内的数据点很难全部满足。

### 6.3 P8 做空平仓的特殊性

P8 做空平仓（`supertrend_tema_strategy_v2.py:615`）：

```python
# P8 大趋势反转 10 根（空头无 pnl 过滤，与回测一致）
if self._trend_reversal_confirmed(ind, idx, "up", 10):
    return SignalResult(close_sig, "P8 大趋势反转(10根上升)")
```

`_trend_reversal_confirmed(direction="up", min_bars=10)` 要求连续 10 根 K 线的 TEMA72、TEMA144、TEMA288 逐根递增。这意味着一旦大盘持续上涨约 50 分钟，无论做空盈亏如何（盈利也平、亏损也平），P8 都会强制平仓。

对比多头 P8：`pnl_ratio > -0.005`（亏损不超过 0.5%）才能触发。做空 P8 无此限制。

从 trade.log 看：7 次平仓中有 **5 次是 P8**，说明在做空行情中，反转确认是主要平仓路径。
